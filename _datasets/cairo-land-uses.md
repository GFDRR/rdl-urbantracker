title: Cairo Land Uses
description: Land use polygons covering the Greater Cairo Region (Cairo and Giza
  governorates). Giza land use data is based on GOPP sources from 2009; Cairo
  land use data is based on GOPP sources from 2019. The datasets were provided
  as image exports by the General Organization of Physical Planning (GOPP) and
  digitized into GIS format by the Transport for Cairo (TfC) team using
  automated workflows. The resulting dataset represents a harmonized but not
  perfectly digitized land use layer for Greater Cairo.
